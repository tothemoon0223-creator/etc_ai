# 마케팅에이전트 디자인 스타일 가이드

## 1. 디자인 원칙

### 5가지 핵심 원칙
1. **단순성 (Simplicity)**: 불필요한 요소는 제거
2. **명확성 (Clarity)**: 사용자가 쉽게 이해할 수 있도록
3. **일관성 (Consistency)**: 모든 화면에서 동일한 경험
4. **접근성 (Accessibility)**: 모든 사용자가 쉽게 접근
5. **효율성 (Efficiency)**: 최소한의 클릭으로 목표 달성

## 3. 타이포그래피

### 폰트 선택
```
영문: Inter (Google Fonts)
한글: Noto Sans KR (Google Fonts)
```

### 폰트 스케일 (Font Scale)
```
H1: 32px | 1.2 line-height | Font-weight: 700
H2: 24px | 1.3 line-height | Font-weight: 700
H3: 20px | 1.4 line-height | Font-weight: 600
H4: 18px | 1.5 line-height | Font-weight: 600

Body: 16px | 1.5 line-height | Font-weight: 400
Small: 14px | 1.6 line-height | Font-weight: 400
Caption: 12px | 1.5 line-height | Font-weight: 400
```

### 사용 규칙
- **페이지 제목**: H1, 색상 #1F2937
- **섹션 제목**: H2, 색상 #1F2937
- **부제목**: H3, 색상 #6B7280
- **본문**: Body, 색상 #1F2937
- **보조 텍스트**: Small, 색상 #6B7280

### 텍스트 강조
```
강한 강조: 폰트 웨이트 700
약한 강조: 색상 변경 (주로 #0066FF)
링크: 파란색 #0066FF + 언더라인
```

## 4. 간격 (Spacing)

### 스페이싱 스케일
```
xs: 4px   (작은 요소 간격)
sm: 8px   (버튼 내부 패딩)
md: 16px  (섹션 내 요소 간격)
lg: 24px  (섹션 간 간격)
xl: 32px  (주요 섹션 간 간격)
2xl: 48px (페이지 간격)
```

### 적용 예시
- 버튼 패딩: `12px 16px` (md 기준)
- 카드 패딩: `24px` (lg)
- 섹션 마진-톱: `48px` (2xl)
- 요소 간 간격: `16px` (md)

## 11. 애니메이션 & 전환

### 전환 속도
```
빠름: 150ms (호버 효과, 상태 변화)
보통: 300ms (모달 오픈, 탭 전환)
느림: 500ms (페이지 로드, 주요 전환)
```

### Easing
```
기본: ease-out (자연스러운 느낌)
강조: cubic-bezier(0.34, 1.56, 0.64, 1) (활기찬 느낌)
```

### 사용 예시
```css
transition: all 300ms ease-out;
```

## 12. 반응형 디자인 (Responsive)

### Breakpoints
```
Mobile: < 640px
Tablet: 640px ~ 1024px
Desktop: > 1024px
```

### 적응 규칙
```
모바일: 단일 컬럼, 풀 너비
태블릿: 2 컬럼
데스크톱: 3~4 컬럼

폰트 크기: 16px (mobile) → 18px+ (desktop)
패딩: 12px (mobile) → 24px (desktop)
```
