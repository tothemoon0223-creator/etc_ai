# 마케팅에이전트 비즈니스 맥락

## 1. 회사 개요

### 기본 정보
- **회사명**: 마케팅에이전트 (Marketing Agent)
- **설립**: 2026년
- **사업 분야**: 마케팅 자동화 소프트웨어 (SaaS)
- **본사**: 서울

### 핵심 사업
유튜브 영상에서 핵심 정보를 자동 추출하여 **네이버 블로그 최적화 콘텐츠**로 변환하는 AI 기반 마케팅 자동화 플랫폼

---

## 2. 시장 현황 분석

### 시장 기회
```
네이버 블로그 시장 현황:
- 월간 활성 사용자: 약 1,500만 명
- 검색 트래픽 점유율: 국내 검색의 25~30%
- 개인 블로거 수: 약 2,000만 명
- 마케팅 활용도: 점진적 증가
```

### 경쟁 상황
| 경쟁사 | 강점 | 약점 |
|------|------|------|
| **수동 작성** | 정확성 높음 | 시간 소요 (많음) |
| **일반 AI 도구** | 빠름 | Naver 특화 X |
| **우리** | 속도 + Naver 특화 | 초기 시장 |

### 타겟 시장
```
1차 타겟: 콘텐츠 마케터, 블로거
   - 시장 규모: 약 500만 명
   - 연간 블로그 글 작성 시간: 약 1,500시간/명
   - 시간 절약 가치: 약 3,000만원/년/명

2차 타겟: 온라인 쇼핑몰 운영자
   - 시장 규모: 약 300만 명
   - SEO 마케팅 수요: 높음
   - 자동화 도구 도입률: 낮음 (기회)

3차 타겟: 중소 기업 마케팅팀
   - 시장 규모: 약 100만 개 기업
   - 마케팅 예산: 제한적
   - 효율화 수요: 높음
```

## 3. 가치 제안 (Value Proposition)

### 핵심 이점
1. **시간 절약**: 90% 이상의 작성 시간 단축
   - 수동 작성: 1시간/글 → 자동화: 5분/글
   
2. **비용 절감**: 외주 비용 제거
   - 블로그 글 외주비: 약 5만원/글
   - 월 20글 기준: 월 100만원 절감
   
3. **검색 최적화**: 네이버 알고리즘 특화
   - Naver SEO 최적화
   - 자동 키워드 분석
   - 검색 순위 상승 기대
   
4. **일관성 유지**: 자동화로 인한 규칙성
   - 정기적 콘텐츠 배포
   - 브랜드 톤 유지
   - 품질 일관성

## 5. 수익 모델

### 가격 정책
```
프리 플랜 (무료):
- 월 5개 글 자동 변환
- 기본 블로그만 지원
- 제한된 수정 기능

베이직 (₩9,900/월):
- 월 50개 글 자동 변환
- 모든 블로그 플랫폼 지원
- 고급 수정 기능
- 기본 분석

프로 (₩29,900/월):
- 무제한 글 변환
- 우선 처리
- AI 큐레이션 기능
- 고급 분석 & 리포팅
- 1:1 지원

엔터프라이즈 (사용자 정의):
- 전용 계정 관리
- API 연동
- 팀 협업 기능
- 커스터마이징
- SLA 보장
```

### 예상 수익 (1년 후)
```
사용자 분포:
- 무료: 50,000명
- 베이직: 5,000명
- 프로: 1,000명
- 엔터프라이즈: 100개

월간 순환 매출 (MRR):
- 베이직: ₩49.5M (5,000 × 9,900)
- 프로: ₩29.9M (1,000 × 29,900)

연간 매출: 약 ₩1.5B
```

## 6. 핵심 메트릭

### KPI (Key Performance Indicators)
```
1. 사용자 획득 (User Acquisition)
   - 월간 신규 가입: 10,000명 목표
   - 유료 전환율: 15% 목표
   
2. 유지율 (Retention)
   - 월간 활성 사용자 (MAU): 70% 이상
   - 고객 이탈률: 5% 이하
   
3. 수익 (Revenue)
   - MRR: 월별 20% 성장
   - 고객 생애 가치 (LTV): ₩500K 이상
   - CAC (고객 획득 비용): LTV의 1/3 이하
   
4. 만족도 (Satisfaction)
   - NPS (순추천 고객지수): 50점 이상
   - 고객 만족도: 4.5/5.0 이상
```
