## 📝 사용 가이드

### 템플릿 작성 방법

1. **헤더 섹션**
   - 뉴스레터 제목과 발행 정보 기입
   - 발행일, 호수 명시

2. **메인 콘텐츠**
   - 특집 기사 1개 (Hero)
   - 주요 기사 3개

3. **보충 섹션**
   - 팁, 통계, 학습 콘텐츠 중 선택
   - 커뮤니티 사례연구 (월 1회)

4. **홍보 섹션**
   - 이벤트, 프로모션, 새로운 기능 소개

5. **푸터**
   - 연락처, 소셜 링크, 구독 관리

### 디자인 주의사항

- **컬러**: 파란색(#0066FF), 오렌지(#FF6B35) 활용
- **이모지**: 시각적 구분을 위해 적절히 사용
- **링크**: 모든 CTA는 [텍스트](링크) 형식으로 작성
- **이미지**: 너비 600px 이상 권장

### 발행 빈도

- **주간**: 매주 월요일 오전 10시
- **기간**: 연중무휴 (휴일 제외)
- **예약 발송**: 일주일 전 작성 완료
