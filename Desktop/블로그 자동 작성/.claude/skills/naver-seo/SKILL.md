# naver-seo 스킬

네이버 블로그의 SEO 기준(C-Rank, D.I.A.)을 바탕으로 글의 검색 순위와 체류시간을 최적화합니다.

## 네이버 알고리즘 기본

### C-Rank (검색 순위)
검색 순위를 결정하는 요소:
- **제목 매칭**: 검색 키워드가 제목에 포함 (★★★★★)
- **본문 키워드**: 핵심 키워드 자연스러운 배치 (★★★★)
- **체류시간**: 방문자가 글을 읽는 시간 (★★★★)
- **댓글·공감**: 상호작용 (★★★)
- **링크**: 외부 링크 (★★)

### D.I.A. (체류시간 최대화)
- **D**esign: 시각 가독성 (소제목, 문단 간격, 한 문단 길이)
- **I**nteractive: 클릭 유도 (이미지, 동영상, CTA)
- **A**ttention: 도입·결론 강화 (처음 100자, 마지막 50자)

## SEO 체크리스트

### A. 제목 & 키워드
- [ ] 제목에 메인 키워드 포함
- [ ] 메인 키워드 자연스럽게 반복 (2~3회)
- [ ] 관련 키워드 배치 (1~2개)

### B. 구조 & 가독성
- [ ] 문단 길이: 평균 50~100자
- [ ] 소제목: 500~800자마다 1개
- [ ] 문단 간격: 엔터 2회
- [ ] 목록: 3개 이상은 불릿/숫자 표시

### C. 도입부 (처음 100자)
- [ ] 명확한 문제 제시
- [ ] 독자 공감
- [ ] 해결책 암시

### D. 본문
- [ ] 논리적 흐름
- [ ] 실제 예시 포함
- [ ] 이미지/코드 삽입 (3000자 이상)

### E. 결론
- [ ] 명확한 정리
- [ ] 다음 액션
- [ ] 공감 유도

## 검증 방식

**SEO-Specialist**: WF2 단계 4에서 위 체크리스트를 검증하고 점수 계산

```
📊 SEO 점수: 82/100

✅ 잘한 부분 (+5점 각)
- 제목에 키워드 포함
- 문단 길이 적절

⚠️ 개선 필요 (-3점 각)
- 키워드 반복 부족
- 결론이 약함

💡 구체적 피드백
1. "AI" 키워드를 본문 3회 반복하세요
2. 4번째 문단(180자)이 너무 깁니다
```

## 주의사항

- **과도한 최적화 피하기**: 키워드 반복만으로는 검색 엔진 패널티
- **자연스러운 배치**: 독자 입장에서 읽기 좋아야 함
- **적절한 이미지**: 많으면 로딩 느려짐
